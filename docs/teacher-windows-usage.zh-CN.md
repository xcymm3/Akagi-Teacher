# Akagi Teacher 教师版中文使用说明

本说明对应 `teacher-v3.7.2.16`，提供 Windows x64 便携包。

## 下载与启动

1. 首次使用，下载 `akagi-teacher-v3.7.2.16-windows-x64.zip`，完整解压后运行其中的 `akagi-teacher.exe`。不要下载 GitHub 自动生成的 Source code 包，不要直接在压缩包里运行。
2. 已有完整运行目录时，可下载独立 `akagi-teacher-v3.7.2.16.exe`，关闭旧程序后放到原 EXE 同目录运行，保留旁边的 `runtime` 文件夹。独立 EXE 不包含完整 Python/uv 运行环境，新用户请选完整 ZIP。
3. 保留已有配置、WebView2 登录资料和对局记录。首次登录在内嵌雀魂页面完成，发行包不包含任何用户账号、配置、日志或牌谱。
4. 需要 Microsoft Edge WebView2 Runtime。缺少时可安装 [微软 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
5. EXE 未做数字签名，可先按随附 SHA256SUMS 文件核验下载。

## 主界面

左侧为内嵌雀魂，右上为模型前三建议、教师解释和局面解读，右下为最近对局记录。顶栏提供自动打牌滑动开关、刷新雀魂和齿轮入口。

“自动打牌”开关控制对局输入、自动排队、结算和继续下一场。关闭后不再发起新的自动操作；已经发给服务器的匹配请求或动作无法撤回。

## 设置与记录窗口

点击齿轮打开独立附属窗口，重复点击复用同一个窗口。它采用自绘标题栏，顶部区域可拖拽，右上角关闭，可从边缘调整大小。打开或切换附属页不会隐藏游戏，也不会关闭自动打牌。最小化主窗口后的后台运行仍不能保证。

左侧保留五项：

- **自动打牌**：排队房间、四麻东风／半庄、默认／自定义操作参数。自定义包含 Lua／随机区间延迟、随机等待上下限、最短思考时间、动作按钮等待、连续点击间隔、悬停、按住、输入校验等待、重试、连续失败刷新阈值及庄家首打等待。参数编辑后点击保存；选择默认会恢复内置参数。
- **界面**：语言、浅色／深色／跟随系统、缩放；即时生效并同步主窗口。
- **软件更新**：版本、自动检查、手动检查、发布页入口、下载进度和取消。
- **历史记录**：雀魂四麻／三麻分组、常用统计、名次分布、实际上分曲线、结算详情、牌谱编号及官方牌谱入口。主界面的“全部记录”直接打开这里。旧记录没有上分数据时标为缺失，不用牌桌点数代替段位分，也不把缺失数据当作零。
- **日志查看**：会话选择、运行日志、事件检查、筛选、刷新、暂停／恢复跟随、自动滚动、打开日志目录；查看不会删除日志或改变对局设置。

关闭窗口时会检查未保存的自动打牌参数；可继续编辑、放弃或保存。保存只合并实际修改的排队与操作参数，不覆盖主界面刚切换的自动打牌开关，也不重启捕获。

不提供模型管理、云端配置、其他平台、捕获、网络及日志配置页面；已有配置继续使用。

## 自动排队与连续对局

先手动登录并进入大厅，选好房间与赛制后开启自动打牌。默认按当前四麻段位选择可进入的最高房间、四麻半庄；指定房间不可进入时按现有规则回退。

连续对局根据大厅状态和服务器事件识别排队、对局、小局与整场结算，再处理确认与下一场。对局内继续使用既有模型与教师决策。不能确认页面状态时等待或按已有恢复规则处理，不盲目点击。

## 本版四麻模型

- 四麻内置权重改为 `06-6m-30m`：约 605 万参数，288 通道、7 个残差块，使用 3,000 万条天凤训练样本，按 2025 年验证集选择第 9 轮权重。
- 2026 年独立测试集包含 7,991,531 条样本，动作预测准确率为 78.6764%；作者原模型在同一测试集为 76.2847%。这些是牌谱动作一致率，不是实战胜率，尚未进行真实对战强度验收。
- 三麻权重保持原样。程序按张量尺寸加载不同规模模型，四麻和三麻均已验证。
- 权重已嵌入 EXE，无需下载或选择额外模型文件。完整便携包中运行 `akagi-teacher.exe` 即可。
- 本机 CPU 测速中，原模型与 06 的单次推理平均耗时分别约 0.31 毫秒与 7.02 毫秒（各 384 次）。这是纯模型推理测速，不能代表不同电脑或真实游戏的完整响应延迟。

## 如何阅读教师说明

- 展示当前内置模型的前三个合法候选、排序及概率，显示顺序保持不变；自动打牌另按下述模型/教师规则决定执行动作。
- 百分比是当前模型偏好，不是和牌率或正确率。文字由独立的 mahjong-helper Go 核心计算，不能视为神经网络的真实理由。
- 完整接入改良、后续进张、综合速度、听牌和率、立直/默听/副露打点、综合收支、危险度和参考排序。每项通常只展示基础牌效与最多两项有区分度的信息；鼠标悬停解释文字可查看具体指标。
- 总结在参考排序支持模型首选时直接推荐；不一致时分别说明模型首选和另一候选的指标优势。仍有不支持的操作或牌形时不强行比较。
- 只保留 **守** 标记：包括已立直对手的现物、立直后通过牌，以及逐事件确认的同巡安全牌。“守”位于牌名右侧，例如“4条 守”；原因文字列出对应对手，不表示对全桌绝对安全。
- “刚打且无人和”仅在响应窗口已结束后纳入。未立直者的同巡安全信息会在其摸牌、吃碰杠或拔北改变手牌后失效；已立直者保留通过牌。仅缺少完整事件流的快照不推断同巡安全。
- 防守指标包含筋、壁、巡目、早外、宝牌和估计失点修正，是综合风险指数，不直接当作放铳率。现物判断与风险指数分开处理。
- 进张依据未见牌估算，包含可能在别人手中的牌，不等于真实牌山。速度、和率与收支沿用上游经验参数和统计表，并非精确真实对局概率。
- 三麻保留原库拔北、宝牌与听牌率转换，统计表未重新校准；国士等上游不支持的牌形回退基础向听/进张。吃碰分析包含后续舍牌；杠和拔北涉及未知岭上牌、新宝牌，暂不编造完整收益结论。
- 模型建议先显示；最多两项深入分析并行，每次分析（含等待）限时12秒。失败/超时显示基础牌效；自动出牌中的教师等待另限时最多2秒，失败则沿用模型动作；旧解释不会贴到新建议。新增分析消耗CPU，不保证零开销。
- Go 分析程序已内嵌，按需释放到临时目录后台运行，不需要另装Go。许可随包保留，详见 `mahjong-helper-LICENSE.txt` 和 `Go-LICENSE.txt`。
- 中文界面使用简体中文解释，其他语言使用英文；建议显示在主窗口右上方。

## 自动出牌仲裁

- 正常模式下，模型与教师首选一致时执行该选择；不一致时，模型首选原始概率严格大于60%则执行模型首选，否则执行教师首选。恰好60%归教师侧，阈值依据未四舍五入的概率。
- 正常模式的教师首选仅在模型当前展示的最多三个候选内产生；弃和模式则比较全部合法舍牌。危险度用于说明和“守”标记，不直接纳入教师首选的排序。
- 教师等待最多2秒，并根据剩余操作时间缩短，预留输入时间；分析不可用、牌形不支持或缺少原始概率时沿用模型选择。等待中若操作窗口或局面已变化，则丢弃过期动作。云端和外部模型无此教师快照时仍沿用原行为。
- 标题栏绿色“自动打牌”滑动开关代表执行已启用，不保证浏览器连接正常；游戏页面未连接、画布不可用或点击失败仍需检查日志。

## 弃和模式与染手防守

内置模型按事件重放检查以下条件，在本方可行动时输出绑定本次局面的弃和建议；外部Python模型暂不接管。高威胁染手对手也计入立直级威胁，同一对手只计一次。

| 条件 | 对手情况 | 自己情况 |
| --- | --- | --- |
| A | 至少一家立直级威胁（实际立直或高威胁染手） | 两向听及以上 |
| B | 至少两家立直级威胁 | 一向听及以上 |
| C | 某家至少两组明副露，且这些明副露内普通宝牌与赤宝牌合计至少3枚 | 两向听及以上 |

- 自己已经立直或处于立直声明阶段时不自动进入弃和。暗杠不计入C的组数及宝牌数；同一张赤宝牌若同时是普通宝牌，按两份宝牌价值计入。
- 一旦进入，普通摸牌、向听改善、模型偏好变高都不退出。小局结束后仍保留提示，直到下一次开局事件重置；重新开始整场对局也会重置。
- 建议区上方显示“弃和中”及进入原因，不显示A/B/C编号；局面解读保持在候选列表下方。模型前三项、排序和概率照常显示，局面解读改为“建议弃和，危险度最低：xx”，可以推荐前三项之外的牌。
- 弃和时从游戏引擎提供的全部合法舍牌中，以Go核心计算的各家风险按听牌率参考值加权求和，选择最小值；同分采用稳定合法动作顺序，不使用牌效或60%模型优先规则。
- 弃和后每次决策重新识别染手倾向，针对目标花色、生张字牌和其他花色分别修正风险，并计入染手打点参考；高威胁者按100%听牌防守权重处理，不代表确认听牌。改碰其他花色等反证会撤销染手修正，但本方弃和状态不退出。普通模式不应用此修正，模型前三项、概率及正常模式仲裁保持不变。
- 染手识别需至少两组兼容副露、近期牌河偏色和手牌进度证据；一组同色副露不触发。第一版阈值和权重为启发式参数，未用实战牌谱校准。详见源码文档 `docs/flush-defence.zh-CN.md`。三麻沿用原有近似听牌率转换，未单独校准。
- 不把染手者改成真正立直；不会增加一发或里宝牌，不会永久保留同巡安全牌。现物与仍有效的通过牌保持安全。
- 风险值已包含失点修正，是参考指数，不是准确放铳率；本阶段只比较当前这一手的风险，尚未增加多巡安全牌储备规划。
- 吃、碰、杠和主动立直默认跳过；合法荣和、自摸正常接受。风险分析只运行快速风险路径，最多等待750毫秒；失败或超时使用基础防守计算，不恢复模型进攻。
- 深入风险分析与基础防守都不能确定合法舍牌时显示无法确定并暂不操作；不会冒充已找到安全牌。自动打牌仍需开关已启用，失效的旧决策不会执行。

## 软件内自动更新

默认启动后约 3 秒检查最新 Release，长时间运行时约每 6 小时检查一次；也可在“软件更新”页手动检查。有新版时查看详情，再选择下载并应用。

匿名 GitHub API 限流或不可用时，本版会回退到同一仓库的 GitHub 官方发布网页，获取对应 EXE 的 SHA-256 与准确大小。仍使用官方地址，校验版本、文件名、SHA-256、文件大小及 Windows x64 程序格式；不使用第三方镜像，不需要填写 GitHub Token。

下载显示连接、下载、校验、替换和重启阶段，以及进度、速度和用时。等待响应头、连续无数据和总下载时间都有超时限制；下载期间可取消，进入替换阶段后不可取消。网页无法提供有效校验信息时保留手动下载入口。

当前牌局未结束时拒绝安装。更新只替换 EXE，保留配置、登录资料、运行环境和记录。文件名可能仍带旧版本号，以软件更新页的内部版本为准。

如果旧版更新器一直卡住或遇到 403，请先手动下载本版 EXE 替换一次；旧程序不会自动获得尚未安装的新更新逻辑。
