# 设置与记录窗口

最终保留五项：**自动打牌、界面、软件更新、历史记录、日志查看**。此前“仅保留历史和日志”误删了已确认的设置项，本版恢复设置项；总览、实时分析、机器人管理等其他页面入口不恢复。

窗口采用自绘标题栏，关闭 Windows 默认系统标题栏。顶部整条区域可拖拽，右侧关闭按钮独立响应。颜色跟随原有主题，窗口仍可从边缘调整大小。

- **自动打牌**：排队房间、四麻东风／半庄，默认／自定义操作参数；自定义中保留 Lua／随机延迟、等待时间、点击校验、重试及失败恢复参数。主界面的自动打牌开关继续保留。
- **界面**：语言、浅色／深色／跟随系统、缩放；即时保存并同步主窗口。
- **软件更新**：版本、自动检查、手动检查、发布页入口、下载进度和取消。保留官方 GitHub 网页回退及 SHA-256 校验。
- **历史记录**：雀魂四麻／三麻统计、名次、实际上分、走势图、本地详情、牌谱编号及官方牌谱入口。
- **日志查看**：会话选择、运行日志、事件检查、筛选、刷新、暂停／恢复跟随、自动滚动、打开日志目录。

打开附属窗口不会切换或隐藏主窗口中的游戏，也不会关闭自动打牌。保存设置仅合并实际修改的排队和操作参数，不覆盖自动打牌开关。自绘关闭按钮和系统关闭请求都保留未保存修改检查；更新安装或保存期间暂不关闭窗口。

模型管理、云端配置、其他平台、捕获、网络和日志配置项仍不提供界面入口，沿用已有配置。此变更不修改模型权重和自动出牌决策规则。
