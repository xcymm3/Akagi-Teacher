# 染手防守与弃和触发

本版只读取公开副露、可见暗杠、牌河、手切/摸切和事件流；不读取对手暗手，不修改神经网络。所有阈值、分支权重及风险倍率是初始启发式策略，尚未通过实战牌谱校准，不是准确染手率或放铳率。

## 染手识别

逐个对手检查：至少有一组数牌明副露；全部可见数牌面子须集中于一个花色，其余可以是字牌。出现另一花色的明副露或暗杠，直接排除当前染手推断；只有字牌副露时不猜花色。暗杠可作为反证，不增加明副露组数。

近期牌河偏色定义：本人至少舍牌6次；最近6张中，至少4张为另外两种花色的数牌，目标花色手切至多1张。字牌不计为“其他花色数牌”。早于最近6张的目标花色舍牌不直接排除染手，目标花色摸切不等同于手切反证。

| 等级 | 条件 | 作用 |
| --- | --- | --- |
| 观察 | 副露兼容，但未满足下列条件 | 不修正风险，不触发弃和 |
| 可疑 | 至少两组明副露且近期牌河偏色 | 仅在已弃和时修正风险 |
| 高威胁 | 至少三组明副露、近期牌河偏色、听牌率参考值至少60 | 计为一家立直级威胁；弃和时听牌防守权重取100% |
| 高威胁的另一条路径 | 至少两组明副露、本人至少舍牌10次、近期牌河偏色、听牌率参考值至少70 | 同上 |

听牌率参考值复用现有Go表：副露数、本人舍牌次数、最后一次新面子副露后的手切数。即时副露后的舍牌不计入后续手切，配合Go接入层的既有约定；加杠不新建面子时点。事件记录不完整时不补猜手切进度，使用表中基础列。三麻仍采用原库近似转换，未单独验证阈值有效性。

这是保守防守规则：“高威胁”不表示真的已经听牌，也不表示已经确认混一色或清一色；对对手没有可见宝牌的情况同样适用。

## 弃和条件

- A：至少一家实际立直或高威胁染手，自己两向听及以上。
- B：至少两家实际立直或高威胁染手，自己一向听及以上。按座位去重。
- C：某家至少两组明副露，且这些明副露中宝牌、赤宝牌合计至少3枚，自己两向听及以上。暗杠既不算明副露组数，也不贡献C的宝牌数；赤牌同时为普通宝牌时按两份加成计入。

自己已经立直或在立直声明阶段不自动进入。弃和持续到下一局开始；威胁下降、向听改善不会退出。模型仍输出原有前三项及概率，弃和时执行教师从全部合法舍牌中选出的最低综合风险牌，跳过正常模式60%规则。

## 逐牌风险

每次弃和决策重新计算各对手的染手等级和目标花色。实际立直者不重复套用染手识别。

普通Go风险已经包含失点，修正公式为：

`修正风险 = 原风险 × [(1-w) + w × 花色系数 × 染手失点参考 / 普通失点参考]`

- 可疑：`w=0.55`；高威胁：`w=0.85`；观察：不调整。
- 目标花色数牌系数：`2.0`。
- 其他两种花色系数：`0.15`；混合分支仍保留误判余量，不当作绝对安全。
- 生张或尚多未见的役牌（未见至少2枚）：`1.8`；其余役牌：`1.4`；其他字牌：`1.3`。剩余枚数、筋、壁等信息已含在原风险中。
- 染手失点参考采用既有副露失点经验表，将可见宝牌数增加2份番数等价权重，亲家照常乘1.5，至少不低于普通失点。这不是给未知暗手精确算番，也不会仅凭没有字牌副露就认定清一色。所有可见宝牌按实际面子牌枚数统计。
- 高威胁对手的防守听牌权重取100%；其他人保持原听牌参考权重。各家修正风险乘听牌权重后求和。

失点仅替换染手分支，不给整条风险再重复叠加一次完整打点。原风险为0的现物或仍有效的同巡安全牌保持0，不会仅因属于目标花色而被抬高。

从全部合法舍牌中选综合风险最小的一张；同分保留稳定合法动作顺序。仍跳过吃碰杠、主动立直，接受合法和牌。Go风险路径最多750毫秒；失败时使用基础风险和同一套染手修正，未立直者的通过牌不会被当作永久安全。

本阶段不规划多巡安全牌储备，不侦测仅凭暗手形成的染手。模型训练、排序、概率及正常模式教师仲裁不受上述风险修正影响。

## 状态与显示

弃和触发原因记录进入时的局面；局面解读根据当前风险写出最低风险牌和当前可疑/高威胁染手对手。之后对手露出另一花色，会撤销对应染手风险及当前警示，但保留本方弃和状态直到下一局。窗口高度继续随内容变化自适应。

染手威胁只改变防守策略，不改真正的立直标志，不计算一发、里宝牌，也不延长同巡安全信息的生命周期。
