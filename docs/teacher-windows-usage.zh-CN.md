# Akagi Teacher 教师版中文使用说明

本说明对应 `teacher-v3.7.2.10`，基于 Akagi v3.7.2，仅提供 Windows x64 便携包。

## 下载与启动

1. 前往 [本仓库 Releases](https://github.com/xcymm3/Akagi-Teacher/releases/latest)，下载 `akagi-teacher-v3.7.2.10-windows-x64.zip`。不要选择 GitHub 自动生成的 `Source code` 压缩包。
2. 将整个压缩包解压到有写入权限的目录。保留程序旁的 `runtime` 文件夹，**不要在压缩包内直接运行，也不要只复制 EXE**。
3. 已有完整旧版运行目录时，也可单独下载 `akagi-teacher-v3.7.2.10.exe`，放到原 EXE 同目录，保留 `runtime` 后运行；新用户请使用完整 ZIP。
4. 关闭正在运行的旧版 Akagi，双击 `akagi-teacher.exe`。本包已带本地模型和 Python/uv 运行环境，无需另行训练模型、安装 Python 或购买云端密钥。
5. 系统需具备 Microsoft Edge WebView2 Runtime。若程序提示缺少 WebView2，从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Runtime 后重试。此 EXE 未做数字签名，Windows 可能提示未知发布者；先确认下载来源和校验值。

## 首次配置

1. 在向导中选择简体中文、游戏平台及抓包方式。推荐使用 Chromium 模式，选择已安装的 Edge 或 Chrome；该方式不要求导入代理证书。
2. 四麻选择内置 `akagi-native`，三麻选择内置 `akagi-native3p`，保持云端推理关闭。
3. 按向导完成配置，由你手动在程序启动的游戏窗口中登录。进入对局后，在“对局 / Game”页的 Bot Show 卡片查看建议，建议悬浮窗每次启动默认打开，可手动关闭。
4. 本版不自动开启自动打牌。无需打开自动打牌即可查看建议和文字解读。请在允许辅助分析的环境中使用。

## 本版四麻模型

- 四麻内置权重改为 `06-6m-30m`：约 605 万参数，288 通道、7 个残差块，使用 3,000 万条天凤训练样本，按 2025 年验证集选择第 9 轮权重。
- 2026 年独立测试集包含 7,991,531 条样本，动作预测准确率为 78.6764%；作者原模型在同一测试集为 76.2847%。这些是牌谱动作一致率，不是实战胜率，尚未进行真实对战强度验收。
- 三麻权重保持原样。程序按张量尺寸加载不同规模模型，四麻和三麻均已验证。
- 权重已嵌入 EXE，无需下载或选择额外模型文件。完整便携包中运行 `akagi-teacher.exe` 即可。
- 本机 CPU 测速中，原模型与 06 的单次推理平均耗时分别约 0.31 毫秒与 7.02 毫秒（各 384 次）。这是纯模型推理测速，不能代表不同电脑或真实游戏的完整响应延迟。

## 如何阅读教师说明

- 展示当前内置模型的前三个合法候选、排序及概率，显示顺序保持不变；自动打牌另按下述模型/教师规则决定执行动作。
- 百分比是当前模型偏好，不是和牌率或正确率。文字由独立的 mahjong-helper Go 核心计算，不能视为神经网络的真实理由。
- 完整接入改良、后续进张、综合速度、听牌和率、立直/默听/副露打点、综合收支、危险度和参考排序。每项通常只展示基础牌效与最多两项有区分度的信息；鼠标悬停解释文字可查看具体指标。
- 总结在参考排序支持模型首选时直接推荐；不一致时分别说明模型首选和另一候选的指标优势。仍有不支持的操作或牌形时不强行比较。
- 只保留 **守** 标记：包括已立直对手的现物、立直后通过牌，以及逐事件确认的同巡安全牌。“守”位于牌名右侧，例如“4条 守”；原因文字列出对应对手，不表示对全桌绝对安全。
- “刚打且无人和”仅在响应窗口已结束后纳入。未立直者的同巡安全信息会在其摸牌、吃碰杠或拔北改变手牌后失效；已立直者保留通过牌。仅缺少完整事件流的快照不推断同巡安全。
- 防守指标包含筋、壁、巡目、早外、宝牌和估计失点修正，是综合风险指数，不直接当作放铳率。现物判断与风险指数分开处理。
- 进张依据未见牌估算，包含可能在别人手中的牌，不等于真实牌山。速度、和率与收支沿用上游经验参数和统计表，并非精确真实对局概率。
- 三麻保留原库拔北、宝牌与听牌率转换，统计表未重新校准；国士等上游不支持的牌形回退基础向听/进张。吃碰分析包含后续舍牌；杠和拔北涉及未知岭上牌、新宝牌，暂不编造完整收益结论。
- 模型建议先显示；最多两项深入分析并行，每次分析（含等待）限时12秒。失败/超时显示基础牌效；自动出牌中的教师等待另限时最多2秒，失败则沿用模型动作；旧解释不会贴到新建议。新增分析消耗CPU，不保证零开销。
- Go 分析程序已内嵌，按需释放到临时目录后台运行，不需要另装Go。许可随包保留，详见 `mahjong-helper-LICENSE.txt` 和 `Go-LICENSE.txt`。
- 中文界面使用简体中文解释，其他语言使用英文；悬浮窗使用30像素固定牌图与横向说明，避免缩放反馈导致抖动。

## 自动打牌与悬浮窗

- 每次启动打开悬浮窗；关闭仅影响当前运行，会保留窗口位置。
- 候选牌名区域使用固定宽度，有无“守”均不改变三行原因文字的起始位置。
- 拖动顶部40像素标题栏移动窗口。标题栏右侧有自动打牌开关，按钮区域不参与拖拽。
- “自动打牌”使用左右滑动开关，点击直接启用或停用并保存状态，无需确认或进入设置页保存。已经发给游戏的操作无法撤回。
- 雀魂和天凤需要 Chromium 捕获模式，并在 Akagi 连接的游戏页面内对局。快捷启用时若模式不符会给出提示，不会假装启用成功。
- 正常模式下，模型与教师首选一致时执行该选择；不一致时，模型首选原始概率严格大于60%则执行模型首选，否则执行教师首选。恰好60%归教师侧，阈值依据未四舍五入的概率。
- 正常模式的教师首选仅在模型当前展示的最多三个候选内产生；弃和模式则比较全部合法舍牌。危险度用于说明和“守”标记，不直接纳入教师首选的排序。
- 教师等待最多2秒，并根据剩余操作时间缩短，预留输入时间；分析不可用、牌形不支持或缺少原始概率时沿用模型选择。等待中若操作窗口或局面已变化，则丢弃过期动作。云端和外部模型无此教师快照时仍沿用原行为。
- 标题栏绿色“自动打牌”滑动开关代表执行已启用，不保证浏览器连接正常；游戏页面未连接、画布不可用或点击失败仍需检查日志。

## 常见情况

- **看不到解释**：确认运行本发行包中的 `akagi-teacher.exe`，使用内置本地模型且云端推理关闭，并查看 Bot Show 或悬浮窗。
- **显示“正在分析”**：等待后台分析；新建议到来后，旧分析结果会被丢弃，不会贴到新候选上。
- **悬浮窗显示不全**：手动拉大窗口或滚动查看。默认三行尺寸约520×228，启动保留位置并恢复紧凑尺寸；长文字会自动换行。
- **抓不到对局数据**：在“对局 / Game”页检查 Capture 状态；如未捕获开局，可重新连接并从下一局开始确认。
- **更新教师版**：从本仓库 Releases 下载。本版应用内更新入口已固定到 `xcymm3/Akagi-Teacher`。可在软件内更新，也可从本仓库Releases手动下载。
- **配置和数据位置**：程序会自动创建运行数据目录。上游可能优先读取系统用户配置目录中已有的 Akagi 配置，备份或迁移时请以实际加载位置为准。发行包不含任何用户登录信息、证书私钥、配置、日志或牌谱。

## 弃和模式（第一阶段）

本版仅加入以下A/B/C条件，尚未加入染手识别或染手风险修正。内置模型按事件重放检查条件，在本方可行动时输出绑定本次局面的弃和建议；外部Python模型暂不接管。

| 条件 | 对手情况 | 自己情况 |
| --- | --- | --- |
| A | 至少一家立直 | 两向听及以上 |
| B | 至少两家立直 | 一向听及以上 |
| C | 某家至少三组明副露，且这些副露内普通宝牌与赤宝牌合计至少2枚 | 两向听及以上 |

- 自己已经立直或处于立直声明阶段时不自动进入弃和。暗杠不计入C的明副露组数；同一张赤宝牌若同时是普通宝牌，按两份宝牌价值计入。
- 一旦进入，普通摸牌、向听改善、模型偏好变高都不退出。小局结束后仍保留提示，直到下一次开局事件重置；重新开始整场对局也会重置。
- 悬浮窗显示“弃和中”及进入原因。模型前三项、排序和概率照常显示，局面解读改为“建议弃和，危险度最低：xx”，可以推荐前三项之外的牌。
- 弃和时从游戏引擎提供的全部合法舍牌中，以Go核心计算的各家风险按听牌率参考值加权求和，选择最小值；同分采用稳定合法动作顺序，不使用牌效或60%模型优先规则。
- 风险值已包含失点修正，是参考指数，不是准确放铳率；本阶段只比较当前这一手的风险，尚未增加多巡安全牌储备规划。
- 吃、碰、杠和主动立直默认跳过；合法荣和、自摸正常接受。风险分析只运行快速风险路径，最多等待750毫秒；失败或超时使用基础防守计算，不恢复模型进攻。
- 深入风险分析与基础防守都不能确定合法舍牌时显示无法确定并暂不操作；不会冒充已找到安全牌。自动打牌仍需开关已启用，失效的旧决策不会执行。

## 软件内自动更新

- 首次需要安装一次v3.7.2.9或更高版本，旧版更新器无法自动切换到教师版仓库。
- 默认启动约3秒后检查 `xcymm3/Akagi-Teacher` 的最新Release；长时间运行时约每6小时检查一次。可在“设置 → 更新”关闭自动检查，或点击“检查更新”立即检查。
- 有新版时出现软件内提示，点击查看详情，再点“立即更新”。程序会下载独立EXE，校验SHA-256、文件大小及Windows x64程序格式，替换当前程序并自动重启。
- 当前牌局未结束时会拒绝安装；可结束牌局后再点“立即更新”。检查和下载失败会保留原程序，设置页不会把网络失败误报成“已是最新版”。
- 只替换当前EXE，保留配置、登录资料、运行环境和牌谱。若原EXE文件名带旧版本号，更新后文件名仍可能保持原样，以“设置 → 更新”的内部版本号为准。
- 自动更新直接连接GitHub，不使用第三方镜像，必须取得GitHub返回的有效SHA-256；目前只支持Windows x64。更新涉及运行环境重大变化时，仍需完整便携包。
- 发布维护：同步 `src/updater/teacher.rs` 的 `VERSION` 与 `teacher-v<四段版本号>` 标签，并上传 `akagi-teacher-v<四段版本号>.exe`。四段版本按数字比较，例如 `.10` 新于 `.9`；缺少EXE或校验值不会安装。

## 校验下载

同时下载 `SHA256SUMS.txt`，在 PowerShell 中执行：

```powershell
Get-FileHash -Algorithm SHA256 .\akagi-teacher-v3.7.2.10-windows-x64.zip
```

将输出与 `SHA256SUMS.txt` 中对应 ZIP 的值比较。解压后的 EXE 校验值也列在校验文件中。
