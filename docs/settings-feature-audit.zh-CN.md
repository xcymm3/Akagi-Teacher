## 左侧导航

总览、实时分析、历史记录、自动打牌、界面、软件更新。主界面的“全部记录”直接打开附属窗口的历史页，不再离开游戏。

实时分析中的危险度和听牌估计来自 Akagi 原分析引擎；仅恢复原有信息展示，不改变教师弃和、染手防守或自动打牌仲裁逻辑。历史统计按三麻/四麻分开，仅累计实际捕获的段位分；图表会说明有上分数据的场数。

## 更新检查的 403

本机验证匿名 REST API 返回 403 且 `x-ratelimit-remaining: 0`，官方发布网页与 EXE 下载地址则正常。教师版现在先访问 API，失败后改读同一 GitHub 仓库的官方发布网页、EXE 对应的 SHA-256 和下载头部的准确大小。仍校验版本、固定仓库和文件名、SHA-256、文件大小，不使用第三方镜像，不需要用户填写 GitHub Token。

网页结构改变或无法读取有效校验信息时会停止自动安装，并保留手动发布页入口。应用更新仍遵循对局中禁止安装的原有检查。

参考：[GitHub REST API 限额说明](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。
