# 历史与日志窗口

当前界面按用户要求仅保留两个附属页面：**历史记录**、**日志查看**。

点击主界面右上角齿轮打开窗口，默认显示历史记录；点击“全部记录”也打开同一窗口。重复打开会复用已有窗口，不切换主窗口页面、不隐藏雀魂、不关闭自动打牌。关闭主窗口时附属窗口一同关闭。

- **历史记录**：雀魂四麻／三麻统计、结算名次与实际段位分增减、名次分布、上分走势、本地详情、牌谱编号及官方牌谱入口。缺失的旧上分数据不会当作零分。
- **日志查看**：复用原日志查看器，支持历史会话选择、运行日志、事件检查、筛选、刷新、暂停／恢复实时跟随、自动滚动和打开日志目录。查看日志不会改变对局设置或删除日志文件。

总览、实时分析、自动打牌参数、界面偏好、软件更新设置、模型管理、云端配置等页面均无界面入口。主界面的游戏、三选建议和自动打牌开关继续保留，原有配置继续使用。

后台自动更新检查和发现新版时的临时提示保留。更新提示不属于侧栏页面，仍遵循对局中禁止安装更新的原有检查。
