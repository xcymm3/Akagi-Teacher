# 精简设置窗口

本文适用于当前源码中的精简界面；旧版 EXE 需在后续打包后升级。

点击主窗口右上角齿轮打开附属设置窗口。重复点击会唤起同一个窗口。设置窗口不会切换主窗口页面、隐藏雀魂或关闭自动打牌；关闭主窗口时设置窗口一起关闭。

左侧导航现为总览、实时分析、历史记录、自动打牌、界面、软件更新六类。原页面功能取舍见 [完整功能对照](settings-feature-audit.zh-CN.md)。偏好设置保留三个分类：

- **自动打牌**：自动排队房间、四麻东风／半庄、默认／自定义操作参数。总开关保留在主窗口顶栏。
- **界面**：语言、浅色／深色／跟随系统、界面缩放，即时保存并同步到主窗口。
- **软件更新**：当前版本、自动检查、手动检查、更新详情、下载进度和取消。主窗口更新提醒也会打开此附属窗口。应用更新需要重启程序，仍遵循已有的对局中禁止应用更新检查。

选择“自定义”可调整 Lua／随机区间延迟、随机等待上下限、最短思考时间、动作按钮等待、连续点击间隔、悬停等待、按住时间、输入校验等待、重试次数、连续失败刷新阈值和庄家首打额外等待。选择“默认”恢复程序内置参数，点击“保存”后生效。

自动打牌参数须点击“保存”。关闭未保存的窗口时，可继续编辑、放弃并关闭或保存。保存失败保留编辑内容；保存只修改实际编辑的排队或操作参数，不覆盖主窗口的自动打牌开关，不重启捕获。进行中的决策可完成原操作，后续决策读取新参数；已发起的排队保持原房间与赛制。

设置中不再提供悬浮窗、多平台、数据捕获、本地模型、云端模型、网络或日志配置。主界面移除通向旧模型管理、日志及配置向导的导航入口；底层兼容模块及已有配置文件不在本次变更中删除或重写。

本变更解决打开设置造成的页面隐藏问题，不改变最小化窗口时的后台运行限制。
