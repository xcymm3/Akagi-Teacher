# 编译缓存管理

项目的 `.cargo/config.toml` 为开发和测试配置 `debug = 0`、`incremental = false`，减少完整调试信息和增量缓存占用。从本项目及其子目录运行 Cargo 时自动生效，不需要每次手动设置环境变量。

该配置不改变模型、教师逻辑、测试断言、优化级别或发布版构建参数；完整调试信息减少，重复测试编译可能更慢。没有设置缓存大小的硬上限，依赖及不同 feature 组合的编译产物仍会占用空间。

- 主项目 `target/debug` 是可重建的开发／测试产物，需要时可清理。
- 保留 `target/release`，用于复用发布版编译缓存。
- `native_bot/target` 是另一个编译目录，本次没有清理。
- 成品 EXE、`runtime`、模型权重、对局记录及训练数据不属于本次清理范围。

清理后不立即运行完整 Rust 编译或测试，以免立刻重建缓存；下次需要验证代码修改时，再以精简配置重新编译。首次测试会重编译依赖，时间比缓存命中时长。
